# Menus de Personagem (C) e Árvores de Habilidades (S)

## Os dois menus contém pontos navegaveis pelo dpad e quando tem pontos para serem distribuidos, novos nós aparecem para a navegação.

## Cores
#### Verde #09B200 - Pontos de navegação do dpad
#### Laranja #FD6100 - Pontos de Ponte entre os menus direito e esquerdo
#### Rosa #B2007C - Quando há pontos de habilidade(fame/fama) para distribuir nas skills esses pontos devem aparecer abaixdo da skill possivel de ser melhorada
#### Amarelo #E6C12A - Ponto de referencia quando houver a troca de abas do menu de habilidades
#### Ciano #0BE0EF - Ponto de refernecia para a troca de abas com L2 e R2 como é feito na aba de pet e inventario
